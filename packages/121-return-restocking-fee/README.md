## Frequently Asked Questions (Direct Citation Q&A)
### Q: Why does a product return cost e-commerce sellers so much more than the refunded price?
A: When an order is returned, the merchant loses five separate cost layers that are never recovered: (1) original outbound shipping subsidy, (2) return shipping label postage ($7–$14), (3) 3PL return receiving, inspection, and polybagging labor ($2.50–$4.50), (4) non-refundable Stripe/PayPal/BNPL payment processing fees (2.9%–5.99%), and (5) damaged or unsellable open-box write-offs.

### Q: When should a store use a Returnless Refund (Keep-It rule) instead of shipping the item back?
A: Whenever your Reverse Handling Cost (Return Label + 3PL Inspection Fee) is greater than your Recoverable Inventory Value (`Unit COGS * (1 - Unsellable Write-Off %)`). For example, if an item has $6.00 in COGS with a 30% open-box damage rate ($4.20 recoverable value), paying $10.50 in return shipping and 3PL fees to get it back loses $6.30 compared to letting the customer keep it.

### Q: What is a fair restocking or return label fee for DTC brands in 2026?
A: Over 65% of DTC apparel, footwear, and home brands now deduct a $5.95 to $9.95 return shipping/restocking fee for cash refunds while waiving the fee if the shopper chooses an instant exchange or store credit. This recovers 60%–85% of your reverse logistics cost while nudging shoppers toward exchanges.

### Q: How do cosmetics, supplements, and intimates brands calculate return costs when 100% of returns are written off?
A: For hygiene-restricted categories where returned items cannot legally be restocked (`writeoff_pct = 100%`), paying for a return shipping label has zero inventory recovery value. ReturnMargin Studio models photo-verified Returnless Refunds or exchange-only credits to stop double-bleeding on return postage.
